# Anurag Kaladhar — Artist Portfolio

A responsive, original dark-purple cinematic portfolio starter made with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish your site.

## Personalize before publishing
- Replace the three abstract placeholder artwork cards in `index.html` with your own art images.
- Update the sample email `hello@example.com`.
- Check the YouTube and Instagram links.
- Change text in About if you'd like it to sound more like you.

No framework or build step required.
